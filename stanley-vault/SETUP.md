# Stanley Setup

## Tour
- Open [[Canvases/Daily Command Center.canvas|Daily Command Center]].
- Open [[Projects/Sample Project|Sample Project]].
- Open [[Bases/README|Bases]] to see the typed object views Stanley expects.

## Import
Drop files into `Sources/Inbox/`. Stanley creates visible source records and queues heavy files instead of blocking the vault.

## Cloud Models
Stanley is local/offline by default. Enable cloud models only when you want OpenAI or Anthropic help for a specific request. Stanley should preview the snippets before anything leaves the device.
