# Stanley Vault

Start here. This vault is plain Markdown, Canvas JSON, and Obsidian-readable structure.

## Core Areas
- [[Calendar/README|Calendar]] - daily command center notes and reviews.
- [[Projects/README|Projects]] - active efforts and project workspaces.
- [[Sources/README|Sources]] - dropped files, imported material, and extraction status.
- [[Concepts/README|Concepts]] - compiled wiki knowledge.
- [[Decisions/README|Decisions]] - decision records and rationale.
- [[Artifacts/README|Artifacts]] - reusable knowledge-work outputs.

- [[Canvases/README|Canvases]] - cowork boards and review surfaces.
